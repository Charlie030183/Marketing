Johnny Castaway

A non-profit preservation effort keeping the 1992 story-telling screensaver usable on modern systems while protecting its original scenes, sounds, timing and character.

Preservation goal

The original mode remains the reference. Modern rendering is an optional presentation layer only: it does not add scenes, redraw characters, rewrite animation timing or replace the preserved audio.
