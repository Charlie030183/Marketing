SmailsMinimalist mobile email
Works with GitHub

Smails is an email client designed to be simple, fast and beautiful, keeping the main functions close at hand while placing less-used features under advanced options.

The project uses a single mobile codebase and prioritizes a clean, responsive and easy-to-understand experience.

Its goal is to make everyday email easier without turning the inbox into a cluttered interface. The project principles include:

  • Simple Gmail sign-in, with other accounts kept under advanced options.
  • Use of existing email accounts without requiring a proprietary mail server.
  • Fast, progressive synchronization and message presentation.
  • Direct controls for spam, sender blocking and undo send.
  • An interface that adapts to phones, tablets, foldables and different screen sizes.

How Smails organizes the experience

The most important functions stay visible and accessible, while less frequent settings remain organized in secondary areas to preserve simplicity.

  • Inbox — quick reading, clear navigation and focus on messages.
  • Compose — writing and sending with as few steps as possible.
  • Accounts — Gmail as the main entry point with progressive support for other providers.
  • Personalization — themes, dark mode, accessibility and automatic interface adaptation.

Privacy and simplicity

Smails is designed to work as a client for the user's existing accounts, reducing unnecessary external dependencies and avoiding proprietary infrastructure when it is not essential.

Technologies used: Dart, Kotlin, YAML and JSON.
