SmailsMinimalist mobile email
Works with GitHub

Smails is a fast, minimalist email app for Android and iOS. It keeps the essentials at hand and hides the rest under Advanced Options.

  • Gmail first; Outlook and others live under Advanced.
  • No mail server of our own — it uses the accounts you already have.
  • Messages arrive one by one so the inbox feels instant.
  • Report spam, block a sender, and undo send for a minute.
  • Family first via direct install; store listing only after Charlie approves.

Project created and directed by Charlie_030183. Internal code stays private. This page only shows the public idea.
